# Conversational AI Quiz Drafts

Teachers create Questions through a private, resumable AI Quiz Draft Conversation rather than publishing AI output directly. The Teacher can provide multiple sources or an instruction, choose a Source Policy, request targeted revisions, edit the draft directly, and explicitly save the approved draft as a Quiz. This preserves Teacher authority over Quranic content while keeping the interaction conversational; source files and the conversation are temporary, while compact Source Evidence remains on saved Questions.

## Considered Options

- One-shot generation with automatic Quiz creation was rejected because AI output requires Teacher verification.
- A general AI tutor was rejected for v1 because the conversation is specifically for building and editing a Quiz.
- Permanent source-file retention was rejected because source material is only needed during drafting.
